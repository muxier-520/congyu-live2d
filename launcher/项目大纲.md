# 丛雨 Live2D — 项目大纲

---

## 项目概述

丛雨（Murasame）是一个 AI 聊天伴侣应用，由 **Node.js 后端**（无框架，纯 `http` 模块）+ **浏览器前端**（Pixi.js + Live2D + 纯 JS）组成，可打包为 Electron 桌面应用。最终目标是将 AI 对话功能集成进 Unity 2D 游戏。

## 三、技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| **桌面壳** | Electron 28 | 可选，用于桌面模式 |
| **前端渲染** | Pixi.js 7.3 | Canvas 2D |
| **Live2D** | Cubism Core + pixi-live2d-display | Cubism 3 模型渲染 |
| **前端代码** | 原生 HTML/CSS/JS | 无框架 |
| **后端** | Node.js `http` 模块 | 零 npm 运行时依赖 |
| **AI 对话** | OpenClaw Gateway / Ollama / Cloud API | 多后端支持 |
| **语音合成** | GPT-SoVITS v2 Pro | 本地推理 |
| **知识库** | 内置倒排索引 | 中文 bigram 分词 |
| **打包** | asar + electron-builder | NSIS 安装包 |

## 四、后端 API 端点

### TTS (语音合成)

| 方法 | 路由 | 功能 |
|------|------|------|
| `POST` | `/api/tts` | TTS 生成（返回原始 WAV） |
| `POST` | `/api/tts-generate` | TTS 生成（返回 JSON `{audio_url}`） |
| `GET` | `/api/tts-latest` | 获取最新 TTS 音频 |
| `GET/POST` | `/api/tts-config` | 获取/更新 TTS 参数 |
| `GET/POST` | `/api/tts-mode` | 切换模式 (local/system/cloud) |
| `GET` | `/api/ref-audio-list` | 列出参考音频 |

### Chat (AI 对话)

| 方法 | 路由 | 功能 |
|------|------|------|
| `POST` | `/api/gateway/v1/chat/completions` | → 代理到 OpenClaw Gateway |
| `POST` | `/api/ollama/v1/chat/completions` | → 代理到本地 Ollama |
| `POST` | `/api/cloud/v1/chat/completions` | → 代理到 Cloud API |

### Knowledge (知识库)

| 方法 | 路由 | 功能 |
|------|------|------|
| `GET` | `/api/knowledge/list` | 列出所有文档 |
| `POST` | `/api/knowledge/upload` | 上传文档 |
| `POST` | `/api/knowledge/search` | 全文搜索 |
| `POST` | `/api/knowledge/delete` | 删除文档 |

### Models (模型管理)

| 方法 | 路由 | 功能 |
|------|------|------|
| `GET` | `/api/models` | 列出所有模型/提供商 |
| `POST` | `/api/models` | 添加模型 |
| `PUT` | `/api/models/:id` | 更新模型 |
| `DELETE` | `/api/models/:id` | 删除模型 |
| `POST` | `/api/models/:id/test` | 测试连接 |
| `POST` | `/api/models/:id/default` | 设为默认 |

### Admin (管理)

| 方法 | 路由 | 功能 |
|------|------|------|
| `GET` | `/api/health` | 健康检查 (GPU/TTS/Ollama 状态) |
| `GET` | `/api/config-reload` | 重新加载配置 |
| `POST` | `/api/bug-report` | 生成 bug 报告 |

### AI Extras

| 方法 | 路由 | 功能 |
|------|------|------|
| `POST` | `/api/search` | DuckDuckGo 网页搜索 |
| `POST` | `/api/ollama/vision` | 视觉分析 |

## 七、关键特性

1. **Live2D 虚拟形象** — Pixi.js 渲染，鼠标追踪，7 种表情 + 12 组动作
2. **AI 多后端对话** — OpenClaw Gateway / Ollama / Cloud API (OpenAI 兼容)
3. **语音合成** — GPT-SoVITS 本地推理，熔断器保护，3 级 fallback，GPU 缓存管理
4. **多对话管理** — 每对话独立系统提示词，支持对话切换/重命名/删除
5. **知识库** — 倒排索引全文搜索，支持中文 bigram 分词
6. **GalGame 模式** — 视觉小说风格 UI，打字机效果，backlog
7. **流式输出** — SSE 实时显示 AI 回复，预生成 TTS 减少等待
8. **模型管理** — 支持多个 AI 提供商动态切换，连接测试
9. **视觉分析** — 上传图片让 AI 描述（Ollama vision 模型）

## 九、未来规划 — Unity 集成

将 AI 对话功能作为 Unity 2D 游戏的内置模块：

```
Unity 游戏
├── 主进程（游戏逻辑 + Live2D + 对话 UI）
└── Node.js 子进程（后端 API 服务，localhost:8888）
     ├── AI 聊天代理
     ├── TTS 语音合成
     └── 知识库 / 对话管理
```

- 后端 HTTP API 保持不变，Unity 通过 HTTP 与之通信
- Unity 中使用 Cubism SDK for Unity 渲染丛雨
- 对话 UI 用 Unity UGUI/UIToolkit 实现
- TTS 音频通过 HTTP 拉取，Unity AudioSource 播放
