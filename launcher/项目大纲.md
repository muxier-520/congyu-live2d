# 丛雨 Live2D — 项目大纲

---

## 项目概述

丛雨（Murasame）是一个开源的 AI 聊天伴侣应用，结合 **Live2D 虚拟形象**、**多后端 AI 对话** 和 **GPT-SoVITS 语音合成**。后端使用 Node.js 原生 `http` 模块（零 npm 运行时依赖），前端使用 Pixi.js + Live2D Cubism Core 渲染虚拟形象，可作为 Electron 桌面应用运行，也可作为浏览器应用使用。

**最终目标：** 将 AI 对话功能集成进 Unity 2D 游戏。

## 功能特性

### 🎭 Live2D 虚拟形象
- Pixi.js 7 渲染 Live2D Cubism 3 模型
- 鼠标追踪视线
- 7 种表情切换 + 12 组动作动画
- 点击互动反馈

### 🤖 AI 多后端对话
- **OpenClaw Gateway** — 自定义 AI 网关
- **Ollama** — 本地 LLM 推理（默认 qwen2.5）
- **Cloud API** — OpenAI 兼容接口（DeepSeek、Qwen、智谱、Moonshot、SiliconFlow 等）
- 支持动态切换后端，连接测试
- 流式输出（SSE 实时显示）

### 🗣️ 语音合成 (TTS)
- **GPT-SoVITS v2 Pro** — 本地语音合成，自定义角色音色
- 熔断器保护（崩溃频繁时自动暂停，2 分钟后尝试恢复）
- 3 级 fallback（标准 → 强制中文 → 自动检测 + 无标点分割）
- GPU 缓存管理（VRAM 阈值监控，自动重启清理）
- 短文本自动补长（<13 字自动扩展，避免截断）
- 长文本智能分块（按标点分割，最大 90 字/块）

### 💬 多对话管理
- 创建/切换/删除对话
- 每对话独立系统提示词（可覆盖全局设定）
- 对话历史持久化（localStorage）
- 从旧版 `chat-history` 自动迁移

### 📚 知识库
- 倒排索引全文搜索
- 中文 bigram 分词 + ASCII 单词分割
- 支持上传/删除/搜索文档
- 按对话关联知识库文档
- 搜索结果自动注入 AI 上下文

### 🎮 GalGame 模式
- 视觉小说风格 UI 覆盖层
- 打字机效果显示文字
- Backlog（对话历史回看）
- 快捷短语面板
- 樱花飘落 + 光晕粒子特效

### 🔧 其他功能
- 网页搜索（DuckDuckGo）
- 视觉分析（上传图片让 AI 描述）
- 文件操作 API
- 健康检查 + Bug 报告生成
- 樱花紫玻璃拟态主题 UI

## 安装步骤

### 1. 克隆仓库

```bash
git clone https://github.com/muxier-520/congyu-live2d.git
cd congyu-live2d
```

### 2. 进入应用目录

```bash
cd launcher/resources/app_current
```

### 3. 创建配置文件

```bash
cp config.example.json config.json
```

编辑 `config.json`，填入你的配置（详见 [配置说明](#配置说明)）。

### 4. 安装 Ollama（可选，用于本地 AI 对话）

从 https://ollama.com 下载安装，然后拉取模型：

```bash
ollama pull qwen2.5:latest
```

### 5. 安装 GPT-SoVITS（可选，用于语音合成）

从 https://github.com/RVC-Boss/GPT-SoVITS 下载 v2 Pro 版本，放置语音模型权重。

### 6. 启动

```bash
node server.js
```

浏览器打开 http://localhost:8888

## 配置说明

配置文件为 `config.json`，基于 `config.example.json` 修改。以下是关键字段：

### 服务器配置

```json
{
  "server": {
    "port": 8888,        // 后端端口
    "host": "127.0.0.1"  // 监听地址
  }
}
```

### AI 后端配置

#### Ollama（本地 LLM）

```json
{
  "ollama": {
    "model": "qwen2.5:latest",  // 使用的模型
    "port": 11434,              // Ollama 端口
    "auto_start": true,         // 自动启动 Ollama
    "search_paths": [           // Ollama 可执行文件路径（按优先级）
      "C:\\Users\\<用户名>\\AppData\\Local\\Programs\\Ollama\\ollama.exe"
    ]
  }
}
```

#### Cloud API（云端 LLM）

```json
{
  "cloud_api": {
    "enabled": true,
    "provider": "deepseek",         // 提供商名称
    "base_url": "https://api.deepseek.com/v1",  // API 地址
    "api_key": "sk-your-key-here",  // API 密钥
    "model": "deepseek-chat"        // 模型名称
  }
}
```

支持的提供商预设：OpenAI、DeepSeek、Qwen、智谱 (Zhipu)、Moonshot、SiliconFlow。

### 语音合成配置

```json
{
  "gpt_sovits": {
    "hostname": "127.0.0.1",
    "port": 9880,                          // GPT-SoVITS 端口
    "auto_start": true,                    // 自动启动
    "search_paths": [                      // GPT-SoVITS 安装路径
      "E:\\GPT-SoVITS-v2pro"
    ]
  },
  "tts": {
    "mode": "local",                       // local / system / cloud
    "ref_audio_path": "models/sounds/congyu_ref.wav",  // 参考音频
    "prompt_text": "我輩の名前は村雨。",                  // 参考文本
    "prompt_lang": "ja",                   // 参考语言
    "text_lang": "auto"                    // 合成语言 (auto/zh/ja)
  }
}
```

### 角色设定

```json
{
  "system_prompt": "你是丛雨(Murasame)，一个温柔可爱的日式女仆。\n\n【角色设定】\n1. 用温柔可爱的语气说中文，简短自然。\n2. 回答简洁，不超过3句话。\n3. 语气温柔，常用'呀''呢''～'等可爱语气词。"
}
```

### 模型管理

```json
{
  "models": [
    {
      "id": "my-deepseek",
      "name": "DeepSeek Chat",
      "type": "openai",
      "url": "https://api.deepseek.com",
      "api_key": "sk-xxx",
      "model": "deepseek-chat",
      "enabled": true
    }
  ],
  "default_model": "my-deepseek"
}
```

### 请求流程

```
用户输入 → 前端 → POST /api/gateway/v1/chat/completions
                → server.js 路由分发
                → services/ai.js 选择后端
                → 代理到 Ollama / Gateway / Cloud API
                → 流式响应回传前端
                → 前端 SSE 实时显示
                → 完成后触发 TTS 预生成
                → POST /api/tts → services/tts.js
                → 调用 GPT-SoVITS → 返回 WAV 音频
                → 前端 Audio 播放
```

## 功能详解

### 多对话系统

每个对话是独立的会话，具有：
- **独立消息历史** — 存储在 localStorage
- **独立系统提示词** — 可覆盖全局 `system_prompt`
- **关联知识库文档** — 可选择性关联

```javascript
// 前端 localStorage 结构
{
  "murasame-conversations": [
    {
      "id": "conv_xxx",
      "name": "日常聊天",
      "messages": [...],
      "system_prompt": null,        // null = 使用全局
      "knowledge_doc_ids": ["doc_1"]
    }
  ],
  "murasame-active-conversation": "conv_xxx"
}
```

### 知识库搜索

基于倒排索引的全文搜索，中文使用 bigram 分词：

```
输入: "村雨丸管理"
分词: ["村雨", "雨丸", "丸管", "管理"]
搜索: 匹配包含这些 token 的文档
排序: 按匹配 token 数量评分
返回: 匹配片段 + 上下文
```

### TTS 保护机制

```
生成请求 → 熔断器检查 → 队列管理 → 分块 → 3 级 fallback
                                                    ↓
                                    标准 → 中文强制 → 自动+无标点
                                                    ↓
                                    音频验证（时长/截断/静音/幻觉）
                                                    ↓
                                    GPU 缓存检查 → 超阈值自动重启
```

### GalGame 模式

通过 MutationObserver 监听聊天消息容器，自动同步到视觉小说风格的对话框：

```
聊天消息 → MutationObserver → VN 对话框 (打字机效果)
                            → Backlog (历史回看)
                            → 快捷短语面板
```

## 开发指南

### 后端模块开发

所有路由模块遵循统一的工厂模式：

```javascript
// routes/example.js
function createExampleRoutes(service, config, state, { log, utils }) {
  const { sendJSON, sendError, collectBody, HTTP_STATUS } = utils;

  function register(handlers) {
    handlers['GET /api/example'] = async (req, res) => {
      sendJSON(res, HTTP_STATUS.OK, { data: 'hello' });
    };

    handlers['POST /api/example'] = async (req, res) => {
      const body = await collectBody(req);
      // 处理逻辑...
      sendJSON(res, HTTP_STATUS.OK, { result: 'ok' });
    };
  }

  return { register };
}

module.exports = { createExampleRoutes };
```

在 `server.js` 中注册：

```javascript
const { createExampleRoutes } = require('./routes/example');
const exampleRoutes = createExampleRoutes(service, config, state, { log, utils });
exampleRoutes.register(handlers);
```

### 前端开发

前端使用原生 JS，`$` 是 `document.querySelector` 的别名：

```javascript
// 读取 DOM
const btn = $('#btn-send');

// 发送请求
const res = await fetchWithTimeout('/api/tts', { ... }, 60000);

// 显示通知
showNotification('操作成功', 'success');

// 显示状态
showStatus('正在处理...');
hideStatus();
```

### 配置热更新

运行时修改 `config.json` 后，调用：

```bash
curl http://localhost:8888/api/config-reload
```

或在前端修改设置面板中的选项，会自动保存到服务器。
