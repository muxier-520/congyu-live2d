## 1. 项目概况

| 项目 | 说明 |
|------|------|
| 名称 | murasame-live2d（丛雨 Live2D 桌面应用） |
| 框架 | Electron 28.3.3 + Express 4.18.2 |
| 主进程 | `electron/main.js`（v2.2），fork server.js 启动后端 |

## 6. 架构与请求链路

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐
│   前端       │────▶│  server.js   │────▶│  Gateway     │
│  app.js     │     │  :8888       │     │  :28789      │
│  (Electron) │     │  Express     │     │  (OpenClaw)  │
└─────────────┘     └──────────────┘     └──────────────┘
                           │
                    ┌──────┴──────┐
                    ▼             ▼
              ┌──────────┐  ┌────────────┐
              │  Ollama  │  │ GPT-SoVITS │
              │  :11434  │  │  :9880     │
              └──────────┘  └────────────┘
```

### AI 后端模式

| 模式 | 端点 | 说明 |
|------|------|------|
| QClaw Gateway（默认） | `/api/gateway/v1/chat/completions` | HTTP SSE 代理到 Gateway，model=openclaw |
| Ollama 本地 | `/api/ollama/v1/chat/completions` | HTTP 代理到 Ollama，默认 qwen2.5:latest |
| 自定义 OpenAI 兼容 | 前端直连 | 配置中的 custom-openai / custom-deepseek（当前禁用） |

### TTS 语音合成

| 级别 | 引擎 | 说明 |
|------|------|------|
| 1（优先） | GPT-SoVITS 本地 | 端口 9880，参考音频 congyu_ref.wav |
| 2（降级） | Windows Speech API | 系统语音合成 |
| 3（兜底） | edge-tts | 微软云端 TTS |

## 7. 配置要点 (config.json)

### 模型列表

| ID | 名称 | 类型 | 状态 |
|----|------|------|------|
| qclaw | qclaw 网关 | gateway (:28789) | ✅ 启用 |
| ollama-local | 本地 Ollama (qwen2.5) | ollama (:11434) | ✅ 启用 |
| custom-openai | 自定义 OpenAI 兼容 | openai (api.openai.com) | ❌ 禁用 |
| custom-deepseek | DeepSeek 等第三方 | openai (api.deepseek.com) | ❌ 禁用 |

### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| server.port | 8888 | 后端监听端口 |
| gateway.url | http://127.0.0.1:28789 | OpenClaw Gateway 地址 |
| gateway.model | openclaw | Gateway 模型标识 |
| tts.mode | local | TTS 模式 |
| tts.text_lang | auto | 自动语言检测（修复中日混合截断） |
| tts.ref_audio_path | src/models/sounds/congyu_ref.wav | 参考音频 |
| security.rate_limit_per_min | 60 | 全局限流（TTS 除外） |
| default_model | qclaw | 默认 AI 后端 |

## 10. 已知问题

### 🔴 严重
1. **proxyRequest body 重复发送** — `req.pipe(p)` + `p.write()` 双重写入，可能导致请求异常
2. **proxyRequest host 头未覆盖** — 转发时保留了前端 host 头，Gateway 可能拒绝

### 🟡 中等
3. **4 个关闭按钮无 handler** — btn-close-memory / btn-close-schedule / btn-close-reminder / btn-close-skills
4. **gateway_ws.js 仍存在** — 已废弃（改用 HTTP SSE），但文件未清理
5. **app_extract 与 src 不同步** — server.js 版本不一致（v3.1 vs v3.2）

### 🟢 低优先级
6. openclaw-features.js 大部分功能为 stub
7. btn-galgame 指向不存在文件
8. 16 个 asar 备份文件未清理
